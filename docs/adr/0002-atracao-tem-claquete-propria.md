# Ganhou claquete própria é atração; título dentro de uma sessão é filme

Um lançamento (A Clínica, Antártida, Voltei na Foto, Marta) que chega com roteiros e claquete própria é uma
**atração** (categoria FILMES, tipo Atração, com keys), mesmo sendo um filme. Um título que só passa numa sessão
(Tela Quente, Supercine…) é um **filme** da tabela `filmes`. A pasta do lançamento segue a regra dos filmes
(`FILMES/TITULOS/_{letra}_/{TÍTULO}`), para o lançamento e uma futura exibição na grade ficarem juntos.

**Opção descartada**: classificar como genérica ("Produções Estúdios Globo", "Filmes Diversos"), que levava o
projeto para um caminho genérico e desfazia o acervo por título.
